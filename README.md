# jarekavi.com

> Personal website 🤙

## Stack

- Astro
- Tailwind CSS
- Cloudflare Pages
- GitHub Actions

## Running locally

1. Clone this repo:

```sh
git clone https://github.com/avizen-j/jarekavi.com.git
```

2. Then go to the project's folder:

```sh
cd jarekavi.com
```

3. Install all dependencies:

```sh
npm install
```

4. Run locally:

```sh
npm run dev
```

## Deployment

The site is deployed to Cloudflare Pages using GitHub Actions and Wrangler. Step by step guide is provided here:

https://developers.cloudflare.com/pages/how-to/use-direct-upload-with-continuous-integration/
